AKEDataはwww.akedata.wikiへ移行しました。旧ドメインのakedata.topは現在こちらへリダイレクトされます。

# AKEDataバージョン更新履歴

### v1.2.8

#### サイドバーとレイアウト

- メインサイドバーと各モジュールのサブサイドバーはドラッグで幅を変更でき、調整後の幅が個別に保存されます。幅が狭い場合、アイコンのある項目はアイコンのみを表示し、アイコンのない項目は識別できるよう名前を残します。
- 左下のグローバル設定と長画像エクスポートボタンは専用の下部領域を使用し、モジュール一覧に重ならなくなりました。

#### 閲覧状態

- 同一の閲覧セッション中にモジュールへ戻ると、以前開いていたページ、項目、スクロール位置を復元します。
- 同じモジュール内でも項目ごとに詳細のスクロール位置を個別に記録します。ページを再読み込みすると一時状態は消去され、開始ページに戻ります。

### v1.2.7

#### ダンジョンとイベント

- ダンジョン詳細に、初回クリア報酬とは別に、理性を消費して繰り返し獲得できる固定報酬とランダム報酬を追加しました。
- イベント一覧のタイムラインは、日単位ではなく実際の開始・終了時刻に合わせてイベントブロックを配置するようになりました。

#### 一覧表示と画像リソース

- キャラクター一覧カードと左サイドバーに属性・職業アイコンを追加し、属性色を再調整して職業 ID に対応する正しいアイコンを表示します。
- キャラクターと武器一覧からレアリティの星表示を、敵一覧から危険度表示を削除しました。フィルター、並び順、詳細データは変更していません。
- リッチテキストの埋め込み、用語リンク、リンクツールチップの各アイコンを現在のデータドメイン経由で解決し、`data.akedata.wiki` の欠落と `//public/...` の不正なパスを修正しました。

### v1.2.6

#### Baker 通信モジュール

- オペレーター、連絡先、グループチャットの全通信記録を閲覧できる Baker モジュールを追加し、種類フィルター、全文検索、URL ディープリンクに対応しました。
- 同じ相手との複数の会話をサイドバーで個別に表示し、会話の選択肢から後続分岐を切り替えられます。
- テキスト、画像、アイテムと任務の添付、システムメッセージ、リアクション、`sns_emoji` 選択肢の画像表示に対応し、アバター、スクロール、PC/モバイル配置を改善しました。

### v1.2.5

#### 画像素材とアセットアップロード

- 画像は `assets/beyond/dynamicassets/gameplay` 以下の元のディレクトリ構造を維持し、各モジュールも新しいパスから取得するようになりました。
- beyond-sdk のディレクトリ判定と不完全な内部マッピングによる素材欠落を修正し、`charremoteicon` と `charremoteicon700` のような同一接頭辞のディレクトリを厳密に区別します。
- AKE Data Tool で画像、Json、または両方を選択してアップロードできます。R2 バケット全体の現在容量と予測ピーク容量を同期前後に確認し、10 GB 以上になる場合は停止します。
- モジュール HTML と JavaScript は `pluginversion` と `jsversion` で個別に更新され、変更のない素材はローカルキャッシュを使用します。
- Baker モジュールは本バージョンに含まれず、`1.2.6` に延期されました。

### v1.2.3

#### モジュールと表示設定

- ミッションモジュールを一時的に非表示とし、「開発中」と明記しました。BuffData、SkillData、SpawnerConfig のデバッグモジュールは無効化され、戦争の残響の入口説明も更新されました。
- 「非表示モジュールを表示」が無効な場合、キャラクター、装備、イベント、Buff などの内部 ID は表示されません。元の値と計算式は常時利用できます。
- 属性補正は出現時、Buff、ステージなどの由来別に集約されます。敵モジュールの属性 Buff も計算へ反映され、非表示モードが無効な場合は Buff ID と属性効果のない Buff を表示しません。

#### 敵とゲームモード

- ダンジョン、危機契約、戦争の残響は、レベル属性、出現時 Buff、補正結果を表示する共通の敵レンダラーを使用します。新しい元素耐性（94–99）へ統一し、旧係数（80–85）は表示しません。
- 戦争の残響のローテーションは開閉でき、進行中・開始前・終了済みを枠線色で区別します。初期状態では進行中のローテーションだけが開き、各ローテーションでは最高難度の敵設定だけが展開されます。
- 3 難度の特性説明と特性強化説明が同じ場合は、難度一覧の前に一度だけ表示します。異なる場合のみ各難度に個別表示します。
- 危機契約の `v2cc-term-param` 表示を修正しました。イベント設定は初期状態で閉じ、ミッションの解放条件は非表示になりました。

#### イベントと操作性

- イベント開始ページに、開始日・終了日・状態を示すカレンダータイムラインを追加しました。日付ツールチップ、画面外タイトルの左端固定、右端に縦幅いっぱいで表示するイベントアイコンに対応し、ホームボタンで戻った際も正しく再描画されます。
- キャラクターと武器のスキル説明に含まれるエスケープ済み改行を修正しました。装備製造コストボタンの横には、既定の装備部品アイコンが表示されます。
- 長画像エクスポートを正式機能として既定で有効にしました。すべてのモジュールでサイドバーを除外し、現在のモジュールまたはページに合ったファイル名を使用します。

#### データ読み込みと告知

- TableCfg の永続キャッシュは Hotfix が変わった場合のみ更新されます。Json と画像は独立した共有データリビジョンを使用し、サイト版や Hotfix の変更だけでは再読み込みされません。
- 告知で Markdown の見出し、リスト、インラインコードなどを正しく描画できるようになりました。About ページと README に「終末地一图流」のデータ協力リンクも追加しました。

### v1.2.2

元の値と計算式は、値をクリックすると常時表示されるポップオーバーで確認できるようになり、遅延ホバー表示を廃止しました。別の値をクリックすると内容が切り替わり、ページの空白部分をクリックするか Esc キーを押すと閉じます。スクロールや画面サイズ変更時に再配置され、モバイルとキーボード操作にも対応します。値そのものの表示スタイルは変更していません。

一部モジュールの親要素のクリック処理により、実際のマウスクリックでポップオーバーを開けない問題を修正しました。また、`chr_0032_lizhiyan` のスキル元データが `[object Object]` と表示される問題を修正しました。

### v1.2.1

モジュール切り替え後や Service Worker の休止・再起動後に、一部のゲーム画像が誤って `www.akedata.wiki` から取得されることがある問題を修正しました。画像パスはページへの挿入時に `data.akedata.wiki` へ同期的に書き換えられます。

Service Worker は登録 URL からデータオリジンと共有データのリビジョンを復元するようになりました。ブラウザが Worker を終了して再起動しても、画像ルーティングの状態が失われません。サイトアイコンもデータオリジンから直接読み込まれます。

`LevelScriptData` の敵データ解析を追加し、ダンジョン、危機契約、戦争の残響のステータス計算へ統合しました。スクリプト内で直接定義された敵、レベル、出現時 Buff と、スポナー経由の条件付き Buff を読み取れるため、SpawnerConfig がないステージでも正しく計算できます。危機契約のタグ Buff の事前読み込みと、タグ変更後の再計算も修正しました。

「元の値」表示を改善しました。ゲーム上の計算変更がない値は従来どおり元の値を表示し、属性補正、Buff、契約タグ、式によって変更された値は、元の値、代入パラメータ、完全な計算式、最終結果を表示します。数式追跡はダンジョン、危機契約、戦争の残響、敵ステータス、およびキャラクター、武器、装備、アイテム説明の計算式に対応しています。

### v1.2.0

ゲームバージョン間のデータ差分表示を追加しました。`Latest` 選択時は、ひとつ前のゲームバージョンの最終 Hotfix と自動比較します。新規データは常に先頭に表示してタグを付け、変更データと詳細 Diff はグローバル設定のテスト機能から有効化できます（既定ではオフ）。

詳細 Diff は画面に実際に表示される情報だけを比較し、削除を赤、追加を緑で表示して非表示フィールドを除外します。イベントは新規判定の対象外です。装備と勲章は個別 ID で判定し、所属セットやカテゴリにもタグを表示します。新規状態はタグのみで区別し、カードの外枠は従来どおりレアリティ色を使用します。
