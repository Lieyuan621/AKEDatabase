# AKEData 版本更新日誌

### v1.2.8

#### 側邊欄與版面配置

- 主左側欄與各模組副左側欄現在可拖曳調整寬度，並分別保存調整後的寬度。側欄較窄時，有圖示的項目只顯示圖示；沒有圖示的項目仍保留名稱，方便辨識。
- 左下角的全域設定與匯出長圖按鈕現在獨占底部區域，不再覆蓋模組清單。

#### 瀏覽狀態

- 同一次瀏覽期間，切換回模組時會還原先前開啟的頁面、項目與捲動位置。
- 同一模組內不同項目會分別記錄詳細內容的捲動位置；重新整理頁面後，這些暫存狀態會清除並回到起始頁。

### v1.2.7

#### 副本與活動

- 副本詳情新增可重複取得的固定獎勵與隨機獎勵，與首通獎勵分開顯示，並標明需消耗理智。
- 活動總覽時間軸改用實際開始與結束時刻定位活動區塊，不再將非零點時間按整天對齊。

#### 總覽與圖片資源

- 角色總覽卡片與左側欄新增屬性、職業圖示，重新校準屬性顏色，並依角色職業編號讀取正確圖示。
- 角色與武器總覽移除星級標籤，敵人總覽移除危險度標籤；篩選、排序與詳情資料維持不變。
- 富文字內嵌圖示、術語連結圖示及連結浮窗圖示統一透過目前資料來源解析，修正缺少 `data.akedata.wiki` 網域與 `//public/...` 錯誤路徑。

### v1.2.6

#### Baker 通訊模組

- 新增 Baker 模組，可瀏覽幹員、聯絡人與群聊的完整通訊記錄，並支援類型篩選、全文搜尋及 URL 深層連結。
- 同一聯絡人有多段對話時，左側欄會依獨立對話分開顯示；對話選項可切換後續分支。
- 支援文字、圖片、物品與任務附件、系統訊息、表情回應及 `sns_emoji` 選項圖片，並改善頭像、捲動區域及桌面/行動版配置。

### v1.2.5

#### 圖片資源與資產上傳

- 圖片改為保留 `assets/beyond/dynamicassets/gameplay` 下的原始目錄結構，各模組已切換至新請求路徑。
- 修正 beyond-sdk 目錄比對及內部映射缺失造成的資源遺漏，精確區分 `charremoteicon` 與 `charremoteicon700` 等同名前綴目錄。
- AKE Data Tool 新增「資產上傳」，可選擇圖片、Json 或同時上傳；同步前後檢查整個 R2 Bucket 的目前與預估峰值容量，達到 10 GB 時阻止上傳。
- 模組 HTML 與 JavaScript 分別使用 `pluginversion`、`jsversion` 判斷更新，未變更資源繼續使用本機快取。
- Baker 模組相關開發未包含於本版本，延後至 `1.2.6`。

### v1.2.3

#### 模組與資訊顯示

- 任務模組暫時隱藏並標記為「開發中」；BuffData、SkillData 與 SpawnerConfig 偵錯模組現已停用。戰爭回響入口說明調整為「查看戰爭回響資料」。
- 未開啟「顯示隱藏模組」時，不再顯示角色、裝備、活動、Buff 等內部 ID；原始值與計算公式改為常態提供。
- 屬性修正會依來源整合為「出生加成」「buff加成」「副本加成」等摘要。敵人模組中的屬性 Buff 也會參與實際計算；隱藏模式關閉時不顯示 Buff ID 或沒有屬性加成的 Buff。

#### 怪物與玩法模組

- 副本、危機合約與戰爭回響改為共用同一套怪物渲染邏輯，統一顯示等級屬性、出生 Buff 與修正結果，並統一使用新的元素抗性資料（94–99）；舊抗性係數（80–85）不再顯示。
- 戰爭回響輪換支援展開與收合，並以外框顏色區分進行中、未開始與已結束。預設只展開進行中的輪換，每個輪換預設只展開最高難度的怪物設定。
- 同一關卡三個難度的特性描述與特性增益相同時，會在所有難度之前統一顯示；只有內容不同時才分別顯示。
- 修正危機合約 `v2cc-term-param` 參數渲染；活動設定預設收合，並隱藏任務解鎖條件。

#### 活動與頁面細節

- 活動起始頁新增活動日曆時間軸，顯示活動開始、結束與目前狀態。時間軸支援日期懸浮提示、畫面外標題靠左顯示，以及上下填滿並靠右對齊的活動圖示；透過模組首頁按鈕返回時也會正確重新渲染。
- 修正角色與武器技能說明中的跳脫換行；裝備製造消耗按鈕左側新增預設使用的裝備元件圖示。
- 匯出長圖功能結束測試狀態並預設開啟。所有模組匯出時都會移除左側欄，並依目前模組或頁面產生正確檔名。

#### 資料載入與公告

- TableCfg 的持久快取現在只在 Hotfix 變更時更新；Json 與圖片使用獨立的共用資料修訂號，不再因網站版本或 Hotfix 變更而重複載入。
- 網站公告現支援 Markdown 標題、清單與行內程式碼等語法。關於頁面與 README 新增「終末地一圖流」資料合作友鏈。

### v1.2.2

「顯示原始值」與計算公式改為點擊數值後開啟常駐浮層，不再使用滑鼠停留提示。點擊另一個數值會切換內容，點擊網頁空白處或按 Esc 關閉；浮層會隨捲動與視窗尺寸變化重新定位，並支援行動裝置與鍵盤操作。數值本身保持原有顯示樣式。

修正部分模組父層點擊事件導致真實滑鼠點擊無法開啟浮層的問題，並修正角色 `chr_0032_lizhiyan` 技能原始值顯示為 `[object Object]`。

### v1.2.1

修正切換模組或 Service Worker 休眠重啟後，部分遊戲圖片可能錯誤地從 `www.akedata.wiki` 請求的問題。圖片路徑現在會在寫入頁面時同步改寫至 `data.akedata.wiki`。

Service Worker 現在會從自身註冊網址恢復資料來源與共用資料修訂號；即使瀏覽器回收並重新啟動 Worker，也不會遺失圖片路由狀態。網站圖示也已改為直接從資料域載入。

新增 `LevelScriptData` 怪物資料解析，並接入一般副本、危機合約與戰爭回響的屬性計算。現在可以讀取腳本內直接定義的敵人、等級與出生 Buff，也可以辨識按生成器施加的條件 Buff；即使關卡沒有 SpawnerConfig，仍能正確計算怪物屬性。危機合約詞條 Buff 的預載與切換後重算也已同步修正。

改進「顯示原始值」功能：未發生業務計算改動的數值繼續按原方式顯示原始值；經過屬性修正、Buff、危機詞條或表達式計算的數值，則會顯示原始值、代入參數、完整計算公式與最終結果。怪物屬性公式現已涵蓋副本、危機合約、戰爭回響和敵人模組，角色、武器、裝備及物品說明中的計算表達式也會保留公式來源。

### v1.2.0

新增跨遊戲版本的資料差異查詢。使用 `Latest` 時，網站會自動與上一個遊戲版本的最後一個 Hotfix 比較；新增資料一律置頂並顯示標籤，修改資料與詳情 Diff 可透過全域設定中的測試功能開關啟用，預設關閉。

詳情 Diff 只比較頁面實際顯示的資訊，刪除內容標紅、新增內容標綠，隱藏欄位不參與比較。活動不進行新增判定；裝備與獎章按具體條目 ID 判斷新增，並同步標記所屬套組或分類。新增狀態只透過標籤區分，卡片外框仍使用原有稀有度顏色。
