# AKEData 版本更新日誌

### v1.1.8

新增偵錯模式與強制重新整理網頁快取功能；修正角色屬性節點及基於物品說明的養成消耗解析；活動類型改由 ActivityTagTable 提供；富文字樣式與術語改為直接讀取 TableCfg；並為具有初始頁面的模組新增側欄首頁按鈕。

### v1.1.6

新增站內公告與更新倒數計時，適配訣的雙形態技能組，改善載入提示，並移除大量已棄用的 v2 模組。

### v1.1.5

推出多語言框架，支援介面、模組、篩選項與資料映射隨語言切換，並加入首批多語言資源。

### v1.1.4

修正資料請求的版本參數，分開應用程式資源與公共資料的更新版本，並統一頁面快取和 Service Worker 的版本判定。

### v1.1.3

物品模組新增消耗品使用效果與合成配方，補充材料和產物關係、詳情樣式及對應的 v3 資料適配。

### v1.1.2

為角色、武器、敵人、裝備、活動、物品、副本、獎章及研究等模組新增分組卡片式總覽入口。

### v1.1.1

重製物品分類篩選，支援摺疊與篩選計數；同時強化請求去重、IndexedDB 快取和資料載入進度顯示。

### v1.1.0

推出基於 TableCfg 和 Json 的 v3 資料適配層，涵蓋主要查詢模組，並加入模組停用機制及大型資料檔案快取。

### v1.0.31

曾加入中英文介面、資料目錄切換及相關國際化設定，但此功能其後已完整回復，未在此階段繼續提供。

### v1.0.30

新增統一請求快取封裝，各頁面改用 akeFetch 載入資料，以減少重複請求並改善模組切換時的載入邏輯。

### v1.0.29

將首頁及各模組的內嵌指令碼拆分至 plugin/js 目錄，集中管理路由、設定、屬性計算和模組控制器。

### v1.0.28

為多數模組參數新增原始數值提示，並修正怪物生命值計算以及「全傷害減免」的顯示錯誤。

### v1.0.27

危機合約新增怪物波次視覺化，支援生成座標、波次切換和連動醒目提示，並修正重複波次的合併統計。

### v1.0.26

危機合約新增敵人屬性檢視，可結合等級、出生 Buff 及所選合約詞條計算並顯示實際屬性。

### v1.0.25

預載並開放受 Token 限制的危機合約模組，支援賽季搜尋、詞條條件與衝突判斷、計分、獎勵、任務和商店顯示。

### v1.0.24

更新角色 v2 技能顯示，修正連攜技與終結技順序，並保留冷卻時間、能量消耗等關鍵參數。

### v1.0.23

正式開放研究模組，強化 Markdown、程式碼醒目提示、目錄索引、錨點跳轉及圖片預覽，並加入機制研究文章。

### v1.0.22

新增基於存取 Token 的模組與內容存取限制，支援 Token 持久化、批次新增和清除，並預載受保護內容。

### v1.0.21

角色 v2 屬性成長表新增物理異常傷害係數與法術異常傷害係數，並依顯示模式提供不同精度。

### v1.0.20

調整敵人詳細屬性的順序與部分名稱，提前抗打斷和處決項目，並統一傷害加成詞條的表述。

### v1.0.19

裝備模組新增裝備 ID 顯示，同時整理角色、武器和裝備 v2 樣式，並修正屬性配色與成長數值選取。

### v1.0.18

新增模組和項目深層連結，導覽時同步網址列並處理隱藏或不存在的內容，同時完善角色屬性修正類型顯示。

### v1.0.17

武器 v2 正式推出，提供武器搜尋、等級屬性、突破材料、潛能和技能等詳細資料顯示。

### v1.0.16

裝備 v2 正式推出，依套裝顯示部件、主副屬性、套裝技能、製造配方、精鍛保底及強化資訊。

### v1.0.15

副本 v2 正式推出，支援副本系列、獎勵和敵人詳情，並解析生成設定與 Buff，以顯示波次和修正後屬性。

### v1.0.14

敵人 v2 正式推出，新增搜尋、行動版清單、等級屬性、敵人變種、屬性修正、抗性與失衡資訊。

### v1.0.13

角色 v2 正式推出，重構角色屬性、技能、天賦、潛能和成長資訊，並修正特性、圖片及節點顯示。

### v1.0.12

強化 SkillData v2 時間軸，新增動作篩選、條件分支流程圖、節點顯示控制和影格時長提示，並修正部分怪物數值。

### v1.0.11

新增隱藏的 SkillData v2 偵錯檢視，以時間軸和動作節點顯示技能邏輯，並支援搜尋及原始資料檢視。

### v1.0.10

繼續重構角色 v2，建立新版角色詳情並接入完整角色資料，完善欄位映射與顯示結構。

### v1.0.9

新增 SpawnerConfig 查詢模組，可依場景和設定瀏覽生成器資料，並調整 BuffData 與 SkillData 查詢入口。

### v1.0.8

新增 BuffData 與 SkillData 查詢模組，支援清單瀏覽、搜尋和詳情檢視，為底層戰鬥資料研究提供入口。

### v1.0.7

新增活動資訊查詢，調整角色詞條預設顯示並支援洛茜特殊詞條，同時加入網站瀏覽量統計。

### v1.0.6

在關於頁面新增贊助者清單及對應樣式，完善專案鳴謝資訊的顯示。

### v1.0.5

完成行動版適配，涵蓋角色、武器、敵人、裝備、物品、副本和成就等主要模組及三套主題。

### v1.0.4

為角色、武器和物品模組新增篩選功能，重構清單篩選區域，提升大量項目下的搜尋效率。

### v1.0.3

新增物品查詢介面並註冊物品模組，支援物品清單、詳情及相關基礎資訊顯示。

### v1.0.2

角色頁面新增技能圖示與後勤技能顯示，包括設施類型、技能等級、說明和解鎖條件，並修正相關資料。

### v1.0.1

修正敵人固定屬性資料顯示異常，並同步完善副本頁面中的敵人資訊。

### v1.0.0

AKEData 1.0 正式推出，集中完善副本查詢內容，並將專案版本由 0.99 提升至 1.0。
