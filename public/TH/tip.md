# บันทึกการอัปเดตเวอร์ชัน AKEData

### v1.2.10-1

#### การเปรียบเทียบเวอร์ชันคลังเอกสาร

- เมื่อใช้ข้อมูล Latest คลังเอกสารจะเปรียบเทียบกับ Hotfix สุดท้ายของเกมเวอร์ชันก่อนหน้า เอกสารที่เพิ่มในเวอร์ชันนี้จะถูกปักไว้ด้านบนและทำเครื่องหมายในภาพรวมหน้าเริ่มต้นแบบรวมทุกหมวดหมู่ รวมถึงภายในหมวดหมู่ของไดเรกทอรี ส่วนรายการใหม่ในแต่ละกลุ่มจะแสดงก่อน เวอร์ชันย้อนหลังแบบคงที่จะไม่แสดงเครื่องหมายรายการใหม่

### v1.2.10

#### คลังเอกสาร

- เพิ่มโมดูลคลังเอกสารแบบสาธารณะใหม่ หน้าเริ่มต้นรวบรวมเอกสารทั้งหมดไว้ในที่เดียว พร้อมไดเรกทอรีตามประเภทสื่อและหมวดหมู่ การค้นหาแบบเต็มข้อความ และลิงก์ตรงไปยังกลุ่มเอกสาร
- หน้ารายละเอียดแสดงชื่อและเนื้อหาแบบข้อความมีรูปแบบ รวมถึงภาพต้นฉบับจากคลังเอกสารในเกม และสามารถสลับภาพที่แตกต่างกันตามเพศของตัวละครหลักได้
- คลังภาพและเสียงจะแสดงเฉพาะข้อความถอดเสียงทีละประโยค โดยไม่มีการเล่นเสียง

#### การใช้งานและความเสถียร

- รองรับไดเรกทอรีทั้งเดสก์ท็อปและมือถือ การกู้คืนสถานะการเรียกดู และการส่งออกเป็นภาพยาว
- ปรับปรุงการแสดงเครื่องหมายปิดบังในข้อความมีรูปแบบและการจัดการเมื่อไม่พบภาพ

### v1.2.9

#### เบ็ดเตล็ดและศูนย์รวมภารกิจ

- เพิ่มโมดูลเบ็ดเตล็ดที่ขยายด้วยเครื่องมืออิสระได้ รุ่นแรกครอบคลุมภารกิจรายสัปดาห์ ภารกิจ Protocol Pass และภารกิจกิจกรรมฝึกซ้อม สัญญา Racing Dungeon และทัวร์นาเมนต์
- ภารกิจ Protocol Pass สามารถกรองตามสัปดาห์ และแสดงครบทุกเลเวลในรางวัลทั้งสามสายแล้ว

#### ไอคอนและข้อมูลแหล่งที่มา

- เพิ่มเครื่องมือสร้างไอคอนตัวละครสำหรับเลือกตัวละครและสกิล ดูตัวอย่างภาพรวม และดาวน์โหลดเป็น PNG
- ร้านค้าจะแสดงเงื่อนไขปลดล็อกและระดับ Material Dispatch ส่วนรายละเอียดอุปกรณ์จะระบุแหล่งที่มา เช่น ร้านค้า ภารกิจ และกล่องแม่แบบบนแผนที่ ลิงก์แผนที่ OEM จะคำนวณจาก LevelData แบบไดนามิกเมื่อคลิกเท่านั้น

#### ประสบการณ์และความเสถียร

- ปรับภาพทดแทนเมื่อโหลดรูปไม่สำเร็จให้เป็นแบบเดียวกัน พร้อมแก้ไขการเลื่อนอิสระของโมดูลเบ็ดเตล็ด ปุ่มควบคุมบนมือถือ และเลย์เอาต์รางวัลภารกิจหลายจุด
- โมดูลข้อมูลการต่อสู้ใหม่ `v3_skill` และโมดูลข้อมูล Buff `v3_buff` ยังอยู่ระหว่างตรวจสอบและยังไม่เปิดใช้ในเวอร์ชันนี้

### v1.2.8

#### แถบด้านข้างและเลย์เอาต์

- แถบด้านข้างหลักและแถบด้านข้างย่อยของแต่ละโมดูลสามารถลากเพื่อปรับความกว้างได้แล้ว และจะบันทึกความกว้างที่ปรับไว้แยกกัน เมื่อแถบแคบ รายการที่มีไอคอนจะแสดงเฉพาะไอคอน ส่วนรายการที่ไม่มีไอคอนยังคงแสดงชื่อเพื่อให้ระบุได้
- ปุ่มการตั้งค่าส่วนกลางและส่งออกรูปภาพแบบยาวที่มุมล่างซ้ายจะใช้พื้นที่ด้านล่างโดยเฉพาะ และไม่ทับรายการโมดูลอีกต่อไป

#### สถานะการเรียกดู

- ภายในเซสชันการเข้าชมเดียวกัน เมื่อกลับไปยังโมดูล ระบบจะคืนค่าหน้า รายการ และตำแหน่งการเลื่อนที่เปิดไว้ก่อนหน้า
- ตำแหน่งการเลื่อนรายละเอียดจะถูกบันทึกแยกกันสำหรับแต่ละรายการในโมดูลเดียวกัน เมื่อรีเฟรชหน้าเว็บ สถานะชั่วคราวเหล่านี้จะถูกล้างและกลับไปยังหน้าเริ่มต้น

### v1.2.7

#### ดันเจียนและกิจกรรม

- รายละเอียดดันเจียนจะแสดงรางวัลแบบคงที่และสุ่มที่รับซ้ำได้โดยใช้ Sanity แยกจากรางวัลผ่านครั้งแรก
- บล็อกบนไทม์ไลน์กิจกรรมจะวางตามเวลาเริ่มและสิ้นสุดจริง แทนการจัดแนวเป็นวันเต็ม

#### หน้าภาพรวมและรูปภาพ

- การ์ดตัวละครและแถบด้านข้างจะแสดงไอคอนธาตุและอาชีพ พร้อมปรับสีธาตุใหม่และเลือกไอคอนตาม ID อาชีพ
- นำดาวระดับความหายากออกจากหน้าภาพรวมตัวละครและอาวุธ และนำระดับอันตรายออกจากหน้าภาพรวมศัตรู โดยตัวกรอง การเรียงลำดับ และข้อมูลรายละเอียดไม่เปลี่ยนแปลง
- ไอคอนใน Rich Text ลิงก์คำศัพท์ และ Tooltip จะใช้โดเมนข้อมูลปัจจุบัน แก้ไขกรณีขาด `data.akedata.wiki` และเส้นทาง `//public/...` ที่ไม่ถูกต้อง

### v1.2.6

#### โมดูลการสื่อสาร Baker

- เพิ่มโมดูล Baker สำหรับดูบทสนทนาทั้งหมดของโอเปอเรเตอร์ รายชื่อผู้ติดต่อ และแชตกลุ่ม พร้อมตัวกรองประเภท การค้นหาแบบเต็มข้อความ และลิงก์ลึก URL
- บทสนทนาหลายรายการของผู้ติดต่อคนเดียวกันจะแสดงแยกกันในแถบด้านข้าง และตัวเลือกบทสนทนาสามารถเปลี่ยนเส้นทางถัดไปได้
- รองรับข้อความ รูปภาพ ไฟล์แนบไอเทมและภารกิจ ข้อความระบบ ปฏิกิริยา และรูปภาพตัวเลือก `sns_emoji` พร้อมปรับปรุงอวาตาร์ การเลื่อน และเลย์เอาต์เดสก์ท็อป/มือถือ

### v1.2.5

#### รูปภาพและการอัปโหลดแอสเซต

- รูปภาพจะคงโครงสร้างไดเรกทอรีเดิมภายใต้ `assets/beyond/dynamicassets/gameplay` และทุกโมดูลเปลี่ยนไปใช้พาธใหม่แล้ว
- แก้ไขแอสเซตที่หายไปจากการจับคู่ไดเรกทอรีและแผนผังภายในของ beyond-sdk ที่ไม่ครบถ้วน รวมถึงแยก `charremoteicon` ออกจาก `charremoteicon700` อย่างถูกต้อง
- AKE Data Tool สามารถเลือกอัปโหลดรูปภาพ ข้อมูล Json หรือทั้งสองอย่าง และตรวจสอบขนาดปัจจุบันกับขนาดสูงสุดโดยประมาณของ R2 bucket ทั้งหมด โดยจะหยุดเมื่อถึง 10 GB
- HTML ของโมดูลและ JavaScript ใช้ `pluginversion` กับ `jsversion` แยกกัน ทำให้ทรัพยากรที่ไม่เปลี่ยนแปลงยังใช้แคชในเครื่องได้
- โมดูล Baker ไม่รวมอยู่ในเวอร์ชันนี้และเลื่อนไปเป็น `1.2.6`

### v1.2.3

#### โมดูลและการแสดงข้อมูล

- ซ่อนโมดูลภารกิจชั่วคราวและระบุว่า “กำลังพัฒนา” ปิดใช้งานโมดูลดีบัก BuffData, SkillData และ SpawnerConfig พร้อมปรับคำอธิบายของ Echoes of War
- เมื่อปิด “แสดงโมดูลที่ซ่อน” จะไม่แสดง ID ภายในของตัวละคร อุปกรณ์ กิจกรรม Buff และข้อมูลอื่น ๆ ส่วนค่าดิบและสูตรคำนวณสามารถดูได้ตลอดเวลา
- รวมตัวปรับค่าสถานะตามแหล่งที่มา เช่น ตอนเกิด จาก Buff หรือจากด่าน Buff ที่มีผลต่อค่าสถานะในโมดูลศัตรูจะนำไปคำนวณ และเมื่อปิดโหมดซ่อนจะไม่แสดง ID ของ Buff หรือ Buff ที่ไม่ส่งผลต่อค่าสถานะ

#### ศัตรูและโหมดเกม

- ดันเจียน, Contingency Contract และ Echoes of War ใช้ตัวแสดงผลศัตรูร่วมกันสำหรับค่าสถานะตามระดับ Buff ตอนเกิด และผลหลังปรับค่า โดยใช้ค่าต้านทานธาตุใหม่ (94–99) และไม่แสดงค่าสัมประสิทธิ์เดิม (80–85)
- รอบหมุนเวียน Echoes of War สามารถขยายหรือยุบได้ สีกรอบแยกสถานะกำลังดำเนินการ ยังไม่เริ่ม และสิ้นสุดแล้ว ค่าเริ่มต้นเปิดเฉพาะรอบที่กำลังดำเนินการ และเปิดเฉพาะการตั้งค่าศัตรูระดับยากที่สุด
- หากคำอธิบายคุณลักษณะและโบนัสเหมือนกันทั้งสามระดับ จะแสดงเพียงครั้งเดียวก่อนรายการระดับความยาก หากต่างกันจึงแสดงแยกในแต่ละระดับ
- แก้ไขการแสดง `v2cc-term-param` ใน Contingency Contract การตั้งค่ากิจกรรมจะถูกยุบโดยค่าเริ่มต้น และซ่อนเงื่อนไขปลดล็อกภารกิจ

#### กิจกรรมและหน้าจอ

- หน้าเริ่มต้นกิจกรรมเพิ่มไทม์ไลน์ปฏิทินพร้อมวันเริ่ม วันสิ้นสุด และสถานะ รองรับคำแนะนำวันที่เมื่อชี้เมาส์ ตรึงชื่อที่อยู่นอกจอไว้ด้านซ้าย และแสดงไอคอนเต็มความสูงชิดขวา การกลับด้วยปุ่มหน้าแรกจะแสดงไทม์ไลน์ใหม่อย่างถูกต้อง
- แก้ไขอักขระขึ้นบรรทัดใหม่แบบ escape ในคำอธิบายสกิลตัวละครและอาวุธ พร้อมแสดงไอคอนชิ้นส่วนเริ่มต้นข้างปุ่มต้นทุนการผลิตอุปกรณ์
- การส่งออกรูปภาพยาวพ้นสถานะทดสอบและเปิดใช้โดยค่าเริ่มต้น โดยไม่รวมแถบด้านข้างและใช้ชื่อไฟล์ตามโมดูลหรือหน้าปัจจุบัน

#### การโหลดข้อมูลและประกาศ

- แคชถาวรของ TableCfg จะเปลี่ยนเมื่อ Hotfix เปลี่ยนเท่านั้น ส่วน Json และรูปภาพใช้รุ่นข้อมูลร่วมอิสระ จึงไม่โหลดใหม่เพียงเพราะเวอร์ชันเว็บไซต์หรือ Hotfix เปลี่ยน
- ประกาศรองรับหัวข้อ รายการ และโค้ดในบรรทัดของ Markdown อย่างถูกต้องแล้ว หน้าเกี่ยวกับและ README ยังเพิ่มลิงก์พันธมิตรข้อมูล “终末地一图流”

### v1.2.1

แก้ไขปัญหาที่รูปภาพเกมบางส่วนอาจถูกร้องขอจาก `www.akedata.wiki` อย่างไม่ถูกต้องหลังจากสลับโมดูลหรือเริ่ม Service Worker ใหม่ ขณะนี้เส้นทางรูปภาพจะถูกเขียนใหม่ไปยัง `data.akedata.wiki` แบบซิงโครนัสเมื่อแทรกลงในหน้า

Service Worker จะกู้คืนต้นทางข้อมูลและหมายเลขแก้ไขของข้อมูลที่ใช้ร่วมกันจาก URL การลงทะเบียน ทำให้การกำหนดเส้นทางรูปภาพยังคงถูกต้องแม้เบราว์เซอร์จะหยุดและเริ่ม Worker ใหม่ ไอคอนเว็บไซต์จะโหลดจากต้นทางข้อมูลโดยตรงด้วย

เพิ่มการวิเคราะห์ข้อมูลศัตรูจาก `LevelScriptData` ในการคำนวณค่าสถานะของดันเจียน, Contingency Contract และ Echoes of War ขณะนี้ระบบอ่านศัตรู ระดับ และ Buff ตอนเกิดที่กำหนดโดยตรงในสคริปต์ รวมถึง Buff แบบมีเงื่อนไขจากตัวสร้างได้ จึงคำนวณด่านที่ไม่มี SpawnerConfig ได้ถูกต้อง และแก้ไขการโหลด Buff เงื่อนไขล่วงหน้ากับการคำนวณใหม่หลังเปลี่ยนเงื่อนไขแล้ว

ปรับปรุงคำแนะนำค่าดิบ ค่าที่ไม่มีการเปลี่ยนแปลงจากการคำนวณยังแสดงค่าต้นฉบับ ส่วนค่าที่เปลี่ยนจากค่าสถานะ Buff เงื่อนไขสัญญา หรือนิพจน์ จะแสดงค่าต้นฉบับ พารามิเตอร์ที่แทนค่า สูตรคำนวณเต็ม และผลลัพธ์สุดท้าย การติดตามสูตรครอบคลุมดันเจียน Contingency Contract Echoes of War ศัตรู และนิพจน์ของตัวละคร อาวุธ อุปกรณ์ และไอเทม
