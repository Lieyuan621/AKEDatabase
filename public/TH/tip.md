# บันทึกการอัปเดตเวอร์ชัน AKEData

### v1.1.6

เพิ่มประกาศภายในเว็บไซต์และการนับถอยหลังการอัปเดต รองรับชุดสกิลสองรูปแบบของเจว๋ ปรับปรุงข้อความแจ้งการโหลด และนำโมดูล v2 ที่เลิกใช้งานแล้วจำนวนมากออก

### v1.1.5

เปิดใช้เฟรมเวิร์กหลายภาษา รองรับการเปลี่ยนภาษาให้กับอินเทอร์เฟซ โมดูล ตัวกรอง และการแมปข้อมูล พร้อมเพิ่มทรัพยากรหลายภาษาชุดแรก

### v1.1.4

แก้ไขพารามิเตอร์เวอร์ชันของคำขอข้อมูล แยกเวอร์ชันรีเฟรชของทรัพยากรแอปกับข้อมูลสาธารณะ และรวมเกณฑ์ตรวจสอบเวอร์ชันของแคชหน้าเว็บกับ Service Worker ให้เป็นแบบเดียวกัน

### v1.1.3

เพิ่มเอฟเฟกต์การใช้ไอเทมสิ้นเปลืองและสูตรสังเคราะห์ในโมดูลไอเทม เสริมความสัมพันธ์ระหว่างวัตถุดิบกับผลผลิต รูปแบบหน้ารายละเอียด และการปรับข้อมูล v3 ที่เกี่ยวข้อง

### v1.1.2

เพิ่มทางเข้าสู่หน้าภาพรวมแบบการ์ดจัดกลุ่มให้โมดูลตัวละคร อาวุธ ศัตรู อุปกรณ์ กิจกรรม ไอเทม ดันเจียน เหรียญตรา และงานวิจัย

### v1.1.1

ออกแบบตัวกรองหมวดหมู่ไอเทมใหม่ รองรับการยุบและการนับผลลัพธ์ พร้อมปรับปรุงการตัดคำขอซ้ำ แคช IndexedDB และการแสดงความคืบหน้าการโหลดข้อมูล

### v1.1.0

เปิดใช้ชั้นปรับข้อมูล v3 ที่อิงกับ TableCfg และ Json ครอบคลุมโมดูลค้นหาหลัก พร้อมเพิ่มกลไกปิดใช้งานโมดูลและแคชไฟล์ข้อมูลขนาดใหญ่

### v1.0.31

เคยเพิ่มการสลับอินเทอร์เฟซและไดเรกทอรีข้อมูลภาษาจีนกับอังกฤษ รวมถึงการตั้งค่าความเป็นสากลที่เกี่ยวข้อง แต่ภายหลังฟังก์ชันนี้ถูกย้อนกลับทั้งหมดและไม่ได้ให้บริการต่อในช่วงนี้

### v1.0.30

เพิ่มตัวห่อแคชคำขอแบบรวม และเปลี่ยนทุกหน้าไปโหลดข้อมูลด้วย akeFetch เพื่อลดคำขอซ้ำและปรับปรุงตรรกะการโหลดเมื่อสลับโมดูล

### v1.0.29

แยกสคริปต์แบบฝังของหน้าแรกและแต่ละโมดูลไปยังไดเรกทอรี plugin/js เพื่อจัดการเส้นทาง การตั้งค่า การคำนวณค่าสถานะ และตัวควบคุมโมดูลจากศูนย์กลาง

### v1.0.28

เพิ่มคำแนะนำค่าดิบสำหรับพารามิเตอร์ของโมดูลส่วนใหญ่ พร้อมแก้ไขการคำนวณพลังชีวิตของมอนสเตอร์และข้อผิดพลาดการแสดงผล “การลดความเสียหายทั้งหมด”

### v1.0.27

เพิ่มภาพแสดงเวฟมอนสเตอร์ใน Contingency Contract รองรับพิกัดเกิด การสลับเวฟ และไฮไลต์เชื่อมโยง พร้อมแก้ไขสถิติรวมของเวฟที่ซ้ำกัน

### v1.0.26

เพิ่มการดูค่าสถานะศัตรูใน Contingency Contract โดยคำนวณและแสดงค่าจริงจากเลเวล Buff ตอนเกิด และเงื่อนไขสัญญาที่เลือก

### v1.0.25

โหลดล่วงหน้าและเปิดโมดูล Contingency Contract ที่จำกัดด้วย Token รองรับการค้นหาซีซัน เงื่อนไขและการตรวจความขัดแย้งของข้อสัญญา การคิดคะแนน รางวัล ภารกิจ และร้านค้า

### v1.0.24

อัปเดตการแสดงสกิลตัวละคร v2 แก้ไขลำดับสกิลประสานและสกิลไม้ตาย พร้อมคงพารามิเตอร์สำคัญ เช่น เวลาคูลดาวน์และการใช้พลังงาน

### v1.0.23

เปิดโมดูลวิจัยอย่างเป็นทางการ ปรับปรุง Markdown การไฮไลต์โค้ด สารบัญ การข้ามด้วย Anchor และตัวอย่างภาพ พร้อมเพิ่มบทความวิจัยกลไก

### v1.0.22

เพิ่มข้อจำกัดการเข้าถึงโมดูลและเนื้อหาด้วย Token รองรับการเก็บ Token แบบถาวร การเพิ่มเป็นชุดและการล้าง พร้อมโหลดเนื้อหาที่ป้องกันไว้ล่วงหน้า

### v1.0.21

เพิ่มค่าสัมประสิทธิ์ความเสียหายผิดปกติทางกายภาพและเวทมนตร์ในตารางการเติบโตค่าสถานะตัวละคร v2 พร้อมใช้ความละเอียดต่างกันตามโหมดแสดงผล

### v1.0.20

ปรับลำดับและชื่อบางส่วนของค่าสถานะศัตรูโดยละเอียด ย้ายรายการต้านการขัดจังหวะและประหารขึ้นก่อน พร้อมทำถ้อยคำของตัวเพิ่มความเสียหายให้เป็นแบบเดียวกัน

### v1.0.19

เพิ่มการแสดง ID อุปกรณ์ในโมดูลอุปกรณ์ จัดระเบียบสไตล์ v2 ของตัวละคร อาวุธ และอุปกรณ์ พร้อมแก้ไขสีค่าสถานะและการเลือกค่าการเติบโต

### v1.0.18

เพิ่ม Deep Link สำหรับโมดูลและรายการ ซิงก์แถบที่อยู่ระหว่างนำทางและจัดการเนื้อหาที่ซ่อนหรือไม่มีอยู่ พร้อมปรับปรุงการแสดงประเภทการแก้ไขค่าสถานะตัวละคร

### v1.0.17

เปิดใช้งานอาวุธ v2 อย่างเป็นทางการ มีการค้นหาอาวุธ ค่าสถานะตามเลเวล วัตถุดิบเลื่อนขั้น ศักยภาพ และข้อมูลสกิลโดยละเอียด

### v1.0.16

เปิดใช้งานอุปกรณ์ v2 อย่างเป็นทางการ แสดงชิ้นส่วนตามเซ็ต ค่าสถานะหลักและรอง สกิลเซ็ต สูตรผลิต การันตีการตีขึ้นรูปละเอียด และข้อมูลเสริมพลัง

### v1.0.15

เปิดใช้งานดันเจียน v2 อย่างเป็นทางการ รองรับซีรีส์ดันเจียน รางวัล และรายละเอียดศัตรู พร้อมวิเคราะห์การตั้งค่าการเกิดและ Buff เพื่อแสดงเวฟและค่าสถานะหลังปรับ

### v1.0.14

เปิดใช้งานศัตรู v2 อย่างเป็นทางการ เพิ่มการค้นหา รายการบนมือถือ ค่าสถานะตามเลเวล ศัตรูรูปแบบต่าง ๆ การแก้ไขค่าสถานะ ค่าต้านทาน และข้อมูลเสียสมดุล

### v1.0.13

เปิดใช้งานตัวละคร v2 อย่างเป็นทางการ ปรับโครงสร้างค่าสถานะ สกิล พรสวรรค์ ศักยภาพ และข้อมูลการเติบโต พร้อมแก้ไขลักษณะเฉพาะ รูปภาพ และการแสดงโหนด

### v1.0.12

ปรับปรุงไทม์ไลน์ SkillData v2 เพิ่มตัวกรองแอ็กชัน แผนผังโฟลว์แขนงเงื่อนไข การซ่อนและแสดงโหนด และคำแนะนำระยะเวลาเฟรม พร้อมแก้ไขค่ามอนสเตอร์บางส่วน

### v1.0.11

เพิ่มมุมมองดีบัก SkillData v2 แบบซ่อน แสดงตรรกะสกิลด้วยไทม์ไลน์และโหนดแอ็กชัน พร้อมรองรับการค้นหาและดูข้อมูลดิบ

### v1.0.10

ปรับโครงสร้างตัวละคร v2 ต่อ โดยสร้างหน้ารายละเอียดตัวละครแบบใหม่และเชื่อมข้อมูลตัวละครฉบับเต็ม พร้อมปรับปรุงการแมปฟิลด์และโครงสร้างแสดงผล

### v1.0.9

เพิ่มโมดูลค้นหา SpawnerConfig เพื่อเรียกดูข้อมูลตัวสร้างตามฉากและการตั้งค่า พร้อมปรับทางเข้าสู่การค้นหา BuffData และ SkillData

### v1.0.8

เพิ่มโมดูลค้นหา BuffData และ SkillData รองรับการดูรายการ การค้นหา และหน้ารายละเอียด เพื่อเป็นทางเข้าสำหรับศึกษาข้อมูลการต่อสู้ระดับพื้นฐาน

### v1.0.7

เพิ่มการค้นหาข้อมูลกิจกรรม ปรับการแสดงข้อกำหนดตัวละครเริ่มต้นและรองรับข้อกำหนดพิเศษของลั่วซี พร้อมเพิ่มสถิติการเข้าชมเว็บไซต์

### v1.0.6

เพิ่มรายชื่อผู้สนับสนุนและสไตล์ที่เกี่ยวข้องในหน้าเกี่ยวกับ พร้อมปรับปรุงการแสดงคำขอบคุณของโครงการ

### v1.0.5

ปรับให้รองรับมือถือเสร็จสมบูรณ์ ครอบคลุมโมดูลหลัก ได้แก่ ตัวละคร อาวุธ ศัตรู อุปกรณ์ ไอเทม ดันเจียน และความสำเร็จ รวมถึงธีมทั้งสามแบบ

### v1.0.4

เพิ่มฟังก์ชันกรองในโมดูลตัวละคร อาวุธ และไอเทม ปรับโครงสร้างพื้นที่ตัวกรองรายการ เพื่อเพิ่มประสิทธิภาพการค้นหาเมื่อมีรายการจำนวนมาก

### v1.0.3

เพิ่มอินเทอร์เฟซค้นหาไอเทมและลงทะเบียนโมดูลไอเทม รองรับรายการไอเทม หน้ารายละเอียด และการแสดงข้อมูลพื้นฐานที่เกี่ยวข้อง

### v1.0.2

เพิ่มไอคอนสกิลและการแสดงสกิลโลจิสติกส์ในหน้าตัวละคร รวมถึงประเภทสิ่งปลูกสร้าง เลเวลสกิล คำอธิบาย และเงื่อนไขปลดล็อก พร้อมแก้ไขข้อมูลที่เกี่ยวข้อง

### v1.0.1

แก้ไขความผิดปกติของการแสดงข้อมูลค่าสถานะคงที่ของศัตรู และปรับปรุงข้อมูลศัตรูในหน้าดันเจียนไปพร้อมกัน

### v1.0.0

เปิดตัว AKEData 1.0 อย่างเป็นทางการ โดยปรับปรุงเนื้อหาการค้นหาดันเจียนอย่างครอบคลุม และยกระดับเวอร์ชันโครงการจาก 0.99 เป็น 1.0
