AKEData가 www.akedata.wiki로 이전되었습니다. 기존 도메인 akedata.top은 현재 이곳으로 리디렉션됩니다.

# AKEData 버전 업데이트 내역

### v1.2.10-1

#### 아카이브 버전 비교

- `Latest` 데이터를 사용할 때만 이전 게임 버전의 최종 Hotfix와 비교합니다. 이번 버전에 추가된 아카이브는 시작 페이지 전체 목록과 디렉터리의 각 분류에서 맨 위에 고정하고 표시하며, 그룹 안의 새 항목도 우선 표시합니다. 고정된 과거 버전에서는 신규 표시를 보여 주지 않습니다.

### v1.2.10

#### 아카이브

- 새로운 공개 아카이브 모듈을 추가했습니다. 시작 페이지에서 수록된 모든 아카이브를 한눈에 볼 수 있으며, 매체 및 분류별 디렉터리, 전체 텍스트 검색, 아카이브 그룹 딥 링크를 지원합니다.
- 상세 페이지는 리치 텍스트 제목과 본문, 게임 내 아카이브 원본 이미지를 표시하며 주인공 성별에 따라 달라지는 이미지도 전환할 수 있습니다.
- 영상 및 음성 아카이브는 문장별 텍스트 전사만 제공하며 오디오는 재생하지 않습니다.

#### 사용성 및 안정성

- 데스크톱과 모바일에 맞춘 디렉터리, 탐색 상태 복원, 긴 이미지 내보내기를 지원합니다.
- 리치 텍스트 가림 표시와 이미지 누락 시 대체 처리를 개선했습니다.

### v1.2.9

#### 기타 및 임무 센터

- 각각 독립적으로 확장할 수 있는 기타 모듈을 추가했습니다. 첫 구성에는 주간 임무, 프로토콜 패스 임무와 연무, 계약, 근맥 기경, 경기 대회의 이벤트 임무 분석이 포함됩니다.
- 프로토콜 패스 임무는 주차별 필터를 지원하며 모든 레벨과 세 개의 보상 트랙을 빠짐없이 표시합니다.

#### 아이콘 및 획득 정보

- 캐릭터와 스킬을 선택하고 합성 결과를 미리 본 뒤 PNG로 내려받을 수 있는 캐릭터 아이콘 생성기를 추가했습니다.
- 상점에 잠금 해제 조건과 물자 조달 레벨을 추가했으며, 장비 상세에는 상점, 임무, 지도 장비 템플릿 상자 등의 획득 경로를 보완했습니다. OEM 지도 링크는 클릭할 때만 LevelData를 읽어 동적으로 생성합니다.

#### 사용성 및 안정성

- 이미지 로드 실패 시 대체 표시를 통일하고, 기타 모듈의 독립 스크롤, 모바일 조작 버튼 및 여러 임무 보상 레이아웃을 수정했습니다.
- 새 전투 데이터 모듈 `v3_skill`과 Buff 데이터 모듈 `v3_buff`는 계속 검증 중이므로 이번 버전에서는 공개하지 않습니다.

### v1.2.8

#### 사이드바 및 레이아웃

- 메인 사이드바와 각 모듈의 보조 사이드바 너비를 드래그로 조절할 수 있으며, 조절한 너비는 각각 저장됩니다. 사이드바가 좁아지면 아이콘이 있는 항목은 아이콘만 표시하고, 아이콘이 없는 항목은 식별할 수 있도록 이름을 유지합니다.
- 왼쪽 아래의 전역 설정 및 긴 이미지 내보내기 버튼은 이제 전용 하단 영역을 사용하며 모듈 목록을 가리지 않습니다.

#### 탐색 상태

- 같은 탐색 세션에서 모듈로 돌아오면 이전에 열었던 페이지, 항목 및 스크롤 위치를 복원합니다.
- 같은 모듈 안에서도 항목별 상세 스크롤 위치를 따로 기록합니다. 페이지를 새로 고치면 이러한 임시 상태가 지워지고 시작 페이지로 돌아갑니다.

### v1.2.7

#### 던전 및 이벤트

- 던전 상세 화면에 최초 클리어 보상과 별도로, 이성을 소모해 반복 획득할 수 있는 고정 보상과 무작위 보상을 표시합니다.
- 이벤트 개요 타임라인의 블록 위치를 날짜 단위가 아닌 실제 시작 및 종료 시각에 맞게 표시합니다.

#### 개요 및 이미지 리소스

- 캐릭터와 무기 개요의 희귀도 별 표시 및 적 개요의 위험도 표시를 제거했습니다. 필터, 정렬, 상세 데이터는 그대로 유지됩니다.
- 리치 텍스트 인라인 아이콘, 용어 링크 아이콘, 링크 툴팁 아이콘을 현재 데이터 도메인으로 해석하여 누락된 `data.akedata.wiki` 호스트와 잘못된 `//public/...` 경로를 수정했습니다.

### v1.2.3

#### 모듈 및 정보 표시

- 임무 모듈을 임시로 숨기고 “개발 중”으로 표시했습니다. BuffData, SkillData, SpawnerConfig 디버그 모듈은 비활성화했으며 전쟁의 메아리 진입 설명도 수정했습니다.
- “숨겨진 모듈 표시”가 꺼져 있으면 캐릭터, 장비, 이벤트, Buff 등의 내부 ID를 표시하지 않습니다. 원본 값과 계산식은 이제 항상 사용할 수 있습니다.
- 속성 보정은 출생, Buff, 스테이지 등 출처별로 합쳐 표시됩니다. 적 모듈의 속성 Buff도 실제 계산에 반영되며, 숨김 모드가 꺼져 있으면 Buff ID와 속성 효과가 없는 Buff는 표시하지 않습니다.

#### 적 및 게임 모드

- 던전, 위기 협약, 전쟁의 메아리가 레벨 속성, 출생 Buff, 보정 결과를 위한 공통 적 렌더러를 사용합니다. 새로운 원소 저항 속성(94–99)을 적용하며 기존 계수(80–85)는 표시하지 않습니다.
- 전쟁의 메아리 로테이션을 펼치거나 접을 수 있고 진행 중, 시작 전, 종료 상태를 테두리 색으로 구분합니다. 기본적으로 진행 중인 로테이션만 열리며 각 로테이션에서는 최고 난이도의 적 설정만 펼쳐집니다.
- 한 스테이지의 세 난이도에서 특성 및 특성 강화 설명이 같으면 난이도 목록 앞에 한 번만 표시하고, 내용이 다를 때만 난이도별로 표시합니다.
- 위기 협약의 `v2cc-term-param` 렌더링을 수정했습니다. 이벤트 설정은 기본적으로 접히며 임무 잠금 해제 조건은 숨깁니다.

#### 이벤트 및 인터페이스

- 이벤트 시작 페이지에 시작일, 종료일, 상태를 표시하는 달력 타임라인을 추가했습니다. 날짜 툴팁, 화면 밖 제목의 왼쪽 고정, 오른쪽에 높이를 채우는 이벤트 아이콘을 지원하며 홈 버튼으로 돌아와도 올바르게 다시 렌더링됩니다.
- 캐릭터와 무기 스킬 설명의 이스케이프된 줄바꿈을 수정했습니다. 장비 제작 비용 버튼 옆에는 기본 장비 부품 아이콘이 표시됩니다.
- 긴 이미지 내보내기가 정식 기능으로 전환되어 기본 활성화됩니다. 모든 모듈의 내보내기에서 사이드바를 제외하고 현재 모듈이나 페이지에 맞는 파일명을 사용합니다.

#### 데이터 로드 및 공지

- TableCfg 영구 캐시는 Hotfix가 바뀔 때만 갱신됩니다. Json과 이미지는 독립된 공유 데이터 리비전을 사용하며 사이트 버전이나 Hotfix 변경만으로 다시 로드되지 않습니다.
- 공지에서 Markdown 제목, 목록, 인라인 코드 등을 올바르게 렌더링합니다. About 페이지와 README에 “终末地一图流” 데이터 협력 링크도 추가했습니다.

### v1.2.2

원본 값과 계산식은 이제 값을 클릭하면 유지되는 팝오버로 표시되며, 지연된 마우스 오버 방식은 제거되었습니다. 다른 값을 클릭하면 내용이 전환되고, 페이지 빈 공간을 클릭하거나 Esc를 누르면 닫힙니다. 스크롤과 창 크기 변경에 따라 위치를 조정하며 모바일 및 키보드 조작을 지원합니다. 값 자체의 표시 스타일은 변경하지 않았습니다.

일부 모듈의 상위 클릭 처리 때문에 실제 마우스 클릭으로 팝오버를 열 수 없던 문제를 수정했습니다. 또한 `chr_0032_lizhiyan` 스킬 원본 값이 `[object Object]`로 표시되던 문제를 수정했습니다.

### v1.2.1

모듈 전환 또는 Service Worker 중단·재시작 후 일부 게임 이미지가 잘못해서 `www.akedata.wiki`에서 요청될 수 있는 문제를 수정했습니다. 이미지 경로는 페이지에 삽입될 때 `data.akedata.wiki`로 동기식 변환됩니다.

Service Worker가 등록 URL에서 데이터 출처와 공유 데이터 리비전을 복원하도록 변경했습니다. 브라우저가 Worker를 종료한 뒤 다시 시작해도 이미지 라우팅 상태가 유지됩니다. 사이트 아이콘도 데이터 출처에서 직접 불러옵니다.

`LevelScriptData` 적 데이터 분석을 추가하고 던전, 위기 협약, 전쟁의 메아리 속성 계산에 연결했습니다. 스크립트에 직접 정의된 적, 레벨, 출생 Buff와 스포너를 통해 적용되는 조건부 Buff를 읽을 수 있어 SpawnerConfig가 없는 스테이지도 올바르게 계산됩니다. 위기 협약 태그 Buff 사전 로드와 태그 변경 후 속성 재계산도 수정했습니다.

원본 값 표시 기능을 개선했습니다. 게임 계산으로 변경되지 않은 값은 기존처럼 원본 값을 표시하고, 속성 보정, Buff, 협약 태그 또는 수식으로 변경된 값은 원본 값, 대입 매개변수, 전체 계산식과 최종 결과를 표시합니다. 공식 추적은 던전, 위기 협약, 전쟁의 메아리, 적 속성뿐 아니라 캐릭터, 무기, 장비 및 아이템 설명의 계산식에도 적용됩니다.

### v1.2.0

게임 버전 간 데이터 차이 조회 기능을 추가했습니다. `Latest` 선택 시 이전 게임 버전의 마지막 Hotfix와 자동 비교합니다. 신규 데이터는 항상 상단에 배치되고 태그가 표시되며, 수정 데이터와 상세 Diff는 기본적으로 꺼져 있는 전역 설정의 테스트 기능에서 활성화할 수 있습니다.

상세 Diff는 화면에 실제로 표시되는 정보만 비교하여 삭제 내용은 빨간색, 추가 내용은 초록색으로 표시하고 숨김 필드는 제외합니다. 이벤트는 신규 판정에서 제외됩니다. 장비와 훈장은 개별 ID로 비교하며 소속 세트 또는 분류에도 태그를 표시합니다. 신규 상태는 태그로만 구분하고 카드 외곽선은 기존 희귀도 색상을 유지합니다.

### v1.2.0-pre2

전체 Attribute 매핑을 갱신하고 ID 93–100을 추가하여 14개 언어의 `maps.json`에 모두 동기화했습니다.

적 및 던전 모듈은 이제 새로운 원소 저항 매개변수(ID 94–99)를 사용합니다. 기존 저항 계수 ID 80–85는 관련 능력치 카드, 보정 요약 및 Buff 툴팁에 더 이상 표시되지 않습니다.

### v1.1.8
