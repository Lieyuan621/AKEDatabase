AKEData가 www.akedata.wiki로 이전되었습니다. 기존 도메인 akedata.top은 현재 이곳으로 리디렉션됩니다.

# AKEData 버전 업데이트 내역

### v1.1.9

상시 도전 콘텐츠 “전쟁의 메아리” 전용 모듈을 추가했습니다. 시즌과 로테이션 주기별로 스테이지, 난이도, 평가 칭호, 공훈 보상과 공식 안내를 확인할 수 있습니다. 적 웨이브, 생성 위치 지도, 생성 Buff, 레벨 보정 능력치도 표시하며 웨이브 전환과 지도 연동 강조를 지원합니다.

### v1.1.8

디버그 모드와 웹 캐시 강제 새로고침 기능을 추가했습니다. 캐릭터 능력치 노드와 아이템 설명 기반 육성 비용 분석을 수정하고, 이벤트 유형을 ActivityTagTable에서 제공하도록 변경했습니다. 리치 텍스트 스타일과 용어는 TableCfg에서 직접 읽으며, 초기 페이지가 있는 모듈에는 사이드바 홈 버튼을 추가했습니다.

### v1.1.6

사이트 공지와 업데이트 카운트다운을 추가하고, 결의 이중 형태 스킬 세트에 대응했습니다. 로딩 안내를 개선하고 폐기된 v2 모듈을 다수 제거했습니다.

### v1.1.5

다국어 프레임워크를 출시하여 UI, 모듈, 필터 항목, 데이터 매핑의 언어 전환을 지원하고 첫 다국어 리소스를 추가했습니다.

### v1.1.4

데이터 요청의 버전 매개변수를 수정하고 앱 리소스와 공개 데이터의 갱신 버전을 분리했으며, 페이지 캐시와 서비스 워커의 버전 판정을 통일했습니다.

### v1.1.3

아이템 모듈에 소모품 사용 효과와 제작법을 추가하고, 재료와 결과물 관계, 상세 스타일, 해당 v3 데이터 어댑터를 보완했습니다.

### v1.1.2

캐릭터, 무기, 적, 장비, 이벤트, 아이템, 던전, 업적, 연구 등 모듈에 그룹 카드형 개요 진입점을 추가했습니다.

### v1.1.1

아이템 분류 필터를 개편해 접기와 필터 수 표시를 지원하고, 요청 중복 제거, IndexedDB 캐시, 데이터 로딩 진행 표시를 강화했습니다.

### v1.1.0

TableCfg와 Json 기반 v3 데이터 어댑터 계층을 출시해 주요 조회 모듈을 지원하고, 모듈 비활성화 기능과 대용량 데이터 파일 캐시를 추가했습니다.

### v1.0.31

중문·영문 UI와 데이터 디렉터리 전환 및 관련 국제화 설정을 추가했으나 이후 완전히 되돌려 이 단계에서는 계속 제공하지 않았습니다.

### v1.0.30

통합 요청 캐시 래퍼를 추가하고 각 페이지가 akeFetch로 데이터를 불러오도록 변경해 중복 요청과 모듈 전환 시 로딩 방식을 개선했습니다.

### v1.0.29

홈과 각 모듈의 인라인 스크립트를 plugin/js로 분리하여 라우팅, 설정, 능력치 계산, 모듈 컨트롤러를 중앙 관리하도록 변경했습니다.

### v1.0.28

대부분의 모듈 매개변수에 원시 수치 안내를 추가하고, 적 체력 계산과 '모든 피해 감소' 표시 오류를 수정했습니다.

### v1.0.27

위기 협약에 적 웨이브 시각화를 추가해 생성 좌표, 웨이브 전환, 연동 강조를 지원하고 중복 웨이브의 병합 통계를 수정했습니다.

### v1.0.26

위기 협약에 적 능력치 조회를 추가하여 레벨, 생성 Buff, 선택한 협약 태그를 반영한 실제 능력치를 계산하고 표시하도록 했습니다.

### v1.0.25

Token 제한 위기 협약 모듈을 미리 로드해 공개하고 시즌 검색, 태그 조건과 충돌 판정, 점수, 보상, 임무, 상점 표시를 지원했습니다.

### v1.0.24

캐릭터 v2 스킬 표시를 갱신하고 연계기와 궁극기의 순서를 수정했으며, 재사용 대기시간과 에너지 소모 등 핵심 매개변수를 유지했습니다.

### v1.0.23

연구 모듈을 정식 공개하고 Markdown, 코드 강조, 목차, 앵커 이동, 이미지 미리보기를 강화했으며 메커니즘 연구 글을 추가했습니다.

### v1.0.22

접근 Token 기반 모듈 및 콘텐츠 제한을 추가하고 Token 영구 저장, 일괄 추가와 삭제를 지원했으며 보호 콘텐츠를 미리 로드했습니다.

### v1.0.21

캐릭터 v2 능력치 성장표에 물리 이상 피해 계수와 아츠 이상 피해 계수를 추가하고 표시 모드에 따라 서로 다른 정밀도를 제공했습니다.

### v1.0.20

적 상세 능력치의 순서와 일부 명칭을 조정하고 경직 저항과 처형 항목을 앞으로 옮겼으며 피해 증가 태그 표현을 통일했습니다.

### v1.0.19

장비 모듈에 장비 ID 표시를 추가하고 캐릭터, 무기, 장비 v2 스타일을 정리했으며 능력치 색상과 성장 수치 선택을 수정했습니다.

### v1.0.18

모듈과 항목 딥 링크를 추가해 이동 시 주소 표시줄을 동기화하고 숨겨졌거나 없는 콘텐츠를 처리했으며 능력치 보정 유형 표시를 개선했습니다.

### v1.0.17

무기 v2를 정식 출시하여 무기 검색과 레벨 능력치, 돌파 재료, 잠재 능력, 스킬 등 상세 데이터 표시를 제공했습니다.

### v1.0.16

장비 v2를 정식 출시하여 세트별 부위, 주·보조 능력치, 세트 스킬, 제작법, 정밀 단조 보장, 강화 정보를 표시했습니다.

### v1.0.15

던전 v2를 정식 출시해 시리즈, 보상, 적 상세 정보를 지원하고 SpawnerConfig와 Buff를 분석하여 웨이브와 보정 능력치를 표시했습니다.

### v1.0.14

적 v2를 정식 출시해 검색, 모바일 목록, 레벨 능력치, 적 변종, 능력치 보정, 저항, 불균형 정보를 추가했습니다.

### v1.0.13

캐릭터 v2를 정식 출시해 능력치, 스킬, 재능, 잠재 능력, 성장 정보를 재구성하고 특성, 이미지, 노드 표시를 수정했습니다.

### v1.0.12

SkillData v2 타임라인에 동작 필터, 조건 분기 흐름도, 노드 표시 전환, 프레임 시간 안내를 추가하고 일부 적 수치를 수정했습니다.

### v1.0.11

숨겨진 SkillData v2 디버그 보기를 추가해 타임라인과 동작 노드로 스킬 로직을 표시하고 검색 및 원시 데이터 조회를 지원했습니다.

### v1.0.10

캐릭터 v2 개편을 이어가며 새 상세 화면을 구축하고 전체 캐릭터 데이터를 연동했으며 필드 매핑과 표시 구조를 보완했습니다.

### v1.0.9

SpawnerConfig 조회 모듈을 추가해 장면과 설정별 생성기 데이터를 탐색하도록 하고 BuffData와 SkillData 조회 진입점을 조정했습니다.

### v1.0.8

BuffData와 SkillData 조회 모듈을 추가해 목록 탐색, 검색, 상세 조회를 지원하고 기반 전투 데이터 연구 진입점을 제공했습니다.

### v1.0.7

이벤트 정보 조회를 추가하고 캐릭터 태그 기본 표시를 조정해 로시의 특수 태그를 지원했으며 사이트 방문자 통계를 추가했습니다.

### v1.0.6

소개 페이지에 후원자 목록과 관련 스타일을 추가하여 프로젝트 감사 정보 표시를 보완했습니다.

### v1.0.5

캐릭터, 무기, 적, 장비, 아이템, 던전, 업적 등 주요 모듈과 세 가지 테마의 모바일 대응을 완료했습니다.

### v1.0.4

캐릭터, 무기, 아이템 모듈에 필터를 추가하고 목록 필터 영역을 재구성하여 많은 항목에서의 검색 효율을 높였습니다.

### v1.0.3

아이템 조회 화면을 추가하고 아이템 모듈을 등록하여 아이템 목록, 상세 정보, 관련 기본 정보 표시를 지원했습니다.

### v1.0.2

캐릭터 페이지에 스킬 아이콘과 기지 스킬을 추가해 시설 유형, 스킬 레벨, 설명, 해금 조건을 표시하고 관련 데이터를 수정했습니다.

### v1.0.1

적 고정 능력치 데이터의 비정상 표시를 수정하고 던전 페이지의 적 정보도 함께 보완했습니다.

### v1.0.0

AKEData 1.0을 정식 출시하며 던전 조회 내용을 집중적으로 개선하고 프로젝트 버전을 0.99에서 1.0으로 올렸습니다.
